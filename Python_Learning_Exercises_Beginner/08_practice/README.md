# Practice challenges

Try these without looking at the examples first:

1. Write a program that prints the numbers from 1 to 20.
2. Ask for three numbers and print the largest.
3. Count how many vowels are in a word.
4. Write a function that returns the factorial of a positive integer.
5. Modify `lucky_number.py` so it checks whether any number is divisible by 5.
6. Add a `%` operation to `simple_calculator.py`.

Tip: test your code with normal inputs, zero, and unexpected input where appropriate.
