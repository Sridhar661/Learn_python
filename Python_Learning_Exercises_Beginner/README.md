# Python Learning Exercises — Beginner

A beginner-friendly collection of Python examples organized by topic.

## Requirements
- Python 3.10 or newer is recommended.
- No third-party packages are required.

## How to run a file
1. Download and extract `Python_Learning_Exercises_Beginner.zip`.
2. Open a terminal or Command Prompt in the extracted folder.
3. Run a file with Python, for example:

   ```bash
   python 01_basics/hello_world.py
   ```

   On some systems, use `python3` instead of `python`.

## Folder guide
- `01_basics`: printing, variables, and data types
- `02_conditions`: if/else and comparisons
- `03_loops`: for and while loops
- `04_functions`: defining and calling functions
- `05_data_structures`: lists, tuples, and dictionaries
- `06_strings`: common string operations
- `07_files_and_errors`: basic file handling and exceptions
- `08_practice`: small practice programs

## Suggested learning order
Start at `01_basics`, then move through the numbered folders. Read the comments in each file, run it, and change the values to see what happens.

## Safety note
`07_files_and_errors/file_handling.py` creates a sample text file in the current working directory. Run it from this extracted project folder if you want the file to be created there.
