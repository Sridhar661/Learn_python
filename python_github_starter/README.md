# Python GitHub Contribution Starter

A beginner-friendly Python project: a command-line task tracker that stores tasks in a local JSON file.

## Requirements
- Python 3.10 or newer
- No third-party packages required

## Run
```bash
python main.py
```

## Run tests
```bash
python -m unittest discover -s tests -v
```

## Project structure
```text
python_github_starter/
├── main.py
├── task_manager.py
├── storage.py
├── utils.py
├── tests/
│   ├── test_task_manager.py
│   └── test_utils.py
└── data/
    └── .gitkeep
```

## Ideas for genuine follow-up contributions
1. Add task priorities.
2. Add due dates.
3. Add search by keyword.
4. Add CSV export.
5. Add input validation tests.
6. Add a completed-task report.
7. Improve documentation with examples.

Make changes you understand, test them, and commit each meaningful improvement. Do not generate artificial commits just to manipulate the contribution graph.
