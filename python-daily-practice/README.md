# Python Daily Coding Practice

A collection of Python exercises covering programming fundamentals,
algorithms, data structures, statistics, and file handling.

## Features

- Prime number detection
- Fibonacci sequence generation
- Binary search
- Duplicate removal
- Frequency counting
- Task queue implementation
- Mean, median, minimum, and maximum calculations
- JSON file storage

## Requirements

Python 3.10 or later.

## Run the project

```bash
python main.py
```

## Project structure

- `main.py`: Demonstrates the functions.
- `algorithms.py`: Implements basic algorithms.
- `data_structures.py`: Provides data structure examples.
- `statistics_tools.py`: Contains statistical utilities.
- `file_handler.py`: Handles JSON files.

## Learning goals

Practice writing reusable functions, type hints, error handling,
and clean Python modules.
